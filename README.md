# BehaviourBrain-DOC

Documentation site for **Behaviour Brain Suite** (Decnet Games) — behaviour trees, state machines as a node type, and utility scoring in one deterministic graph for Unity 6, with a recorded-trace replay debugger.

Live site: https://decnet-games.github.io/BehaviourBrain-DOC/

Built with Jekyll + Just the Docs (`remote_theme`), following the Decnet house doc-site standard. Content is sourced from the shipped package's documentation set and the verified listing claims — no prices, no invented claims.
