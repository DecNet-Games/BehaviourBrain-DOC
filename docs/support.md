# Support
{: .no_toc }

## Email
{: .no_toc .text-delta }

**support@decnetgames.com**

To get to a fix quickly, include:

- your Unity version (the package is built and gate-tested on **6000.5.4f1**),
- what you did, in the order you did it,
- and the exact text of any error — Behaviour Brain Suite's errors name the key, tick or element at fault, and that name is usually the fix. See [Troubleshooting]({{ site.baseurl }}/docs/troubleshooting/) first; most named errors resolve there.
