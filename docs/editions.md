# Editions
{: .no_toc }

## One package, the whole system
{: .no_toc .text-delta }

Behaviour Brain Suite has a single edition. There are no tiered versions and no add-on packs: everything documented on this site is in the one box.

## What the package includes

- **Behaviour Brain Suite UPM package** (`com.decnet.behaviour-brain`) — the runtime source, with assembly definitions and the full C# source included.
- **The behaviour runtime** — behaviour trees, `StateMachineNode`, `UtilitySelector` and scorers, the typed blackboard, seeded random, and versioned-JSON graph serialization.
- **The Home window** — graphs, the plain-language setup report and replay entry points, with the welcome screen on first open.
- **The Replay Debugger** editor window (Tools / Decnet Games / Behaviour Brain Suite / Replay Debugger) — plays recorded `.dectrace` runs back tick by tick; recordings only.
- **Two sample scenes** — GuardPatrol and UtilityEnemy, each with the recorded trace of its own run.
- **The EditMode test suite** — the same suite behind the determinism record.
- **The documentation set** — a reference page for every node type, a blackboard reference, the trace-format reference, migration notes, a quick-start, and a plain "what v1 is NOT" page that states the scope limits in writing.
- **Support** via email and Discord — see [Support]({{ site.baseurl }}/docs/support/).

For what the package deliberately does not include, see [What v1 Is Not]({{ site.baseurl }}/docs/what-v1-is-not/).
